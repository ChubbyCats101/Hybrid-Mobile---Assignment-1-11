# PokéJourney Final

แอปกิจกรรมท่องเที่ยวของชมรม ผสานการจัดทีมโปเกมอนกับการลงทะเบียนทริป สำหรับรายวิชา **IN405109 Hybrid Mobile** สัปดาห์ 1–11

**เลือกกิจกรรม → จัดทีม → เข้าสู่ระบบ → ลงทะเบียนพร้อมรูปและจุดนัดพบ → ดูประวัติทริป**

## ฟีเจอร์หลัก

- ค้นหากิจกรรม ดูรายละเอียด และบันทึกรายการโปรด
- Pokédex และจัดทีมโปเกมอนได้สูงสุด 6 ตัว
- สมัครสมาชิก เข้าสู่ระบบ และดูประวัติทริปของตนเอง
- ถ่ายรูป สลับกล้องหน้า/หลัง เลือกรูป ปรับฟิลเตอร์ และบันทึกภาพลงเครื่อง
- แผนที่ OpenStreetMap พร้อมเลือกจุดนัดพบและใช้ตำแหน่งปัจจุบัน
- ตั้งเตือนกิจกรรม และเปิดรายการกิจกรรมที่เคยโหลดขณะออฟไลน์

## เริ่มใช้งาน

ใช้ **Node.js 22.13 ขึ้นไป** และ Expo Go ที่รองรับ **Expo SDK 57** เชื่อมคอมพิวเตอร์กับมือถือบน Wi-Fi เดียวกัน แล้วรันในโฟลเดอร์โปรเจกต์:

```sh
npm ci
npm start
```

สแกน QR ด้วย Expo Go คำสั่งนี้เปิดทั้ง API และแอปพร้อมกัน กด `Ctrl+C` เพื่อหยุด

- แอปเลือก IP ของคอมพิวเตอร์ให้อัตโนมัติ ไม่ต้องสร้าง `.env` สำหรับ LAN ปกติ
- หากโหลดกิจกรรมไม่ได้ ให้ลองเปิด `http://<IP-คอมพิวเตอร์>:3001/health` จากมือถือ
- สร้างบัญชีได้จากหน้าลงทะเบียนกิจกรรม โดยตั้งรหัสผ่าน 8–128 ตัวอักษร

**เปิดผ่านเว็บ:** รัน `npm run api` และ `npm run web` คนละ terminal

### ตั้งค่า API เอง (เมื่อเชื่อมต่ออัตโนมัติไม่ได้)

สร้างไฟล์ `.env` ในโฟลเดอร์เดียวกับ `package.json` แล้วใส่:

```env
EXPO_PUBLIC_API_URL=http://<IPv4-คอมพิวเตอร์>:3001
```

เปลี่ยน `<IPv4-คอมพิวเตอร์>` เป็น IPv4 ของคอมพิวเตอร์ที่รัน API (Windows ดูได้ด้วย `ipconfig`)

| อุปกรณ์ที่เปิดแอป | ที่อยู่ API |
|---|---|
| มือถือจริง | `http://<IPv4-คอมพิวเตอร์>:3001` และใช้ Wi-Fi เดียวกัน |
| Android Emulator | `http://10.0.2.2:3001` |
| เว็บบนคอมพิวเตอร์ที่รัน API | `http://localhost:3001` |

หลังแก้ `.env` ให้หยุดแล้วเปิด `npm start` ใหม่ อย่าใช้ `localhost` บนมือถือจริง เพราะหมายถึงตัวมือถือเอง หากยังเชื่อมต่อไม่ได้ ให้ตรวจว่า API เปิดอยู่และไฟร์วอลล์อนุญาตพอร์ต 3001 บนเครือข่ายส่วนตัว

## หมายเหตุ

- การแจ้งเตือน Android ให้ทดสอบด้วย Development Build; Expo Go มีข้อจำกัด
- แผนที่และข้อมูลโปเกมอนต้องใช้อินเทอร์เน็ต แผนที่ในแอปไม่ต้องใช้ Google Maps API key
- รูปในแท็บกล้องบันทึกลงเครื่องได้ หากต้องการแนบกับทริป ให้เพิ่มรูปในฟอร์มลงทะเบียน
- API เก็บบัญชีและทริปใน `server/.data/journey.sqlite` กิจกรรมเป็นข้อมูลตัวอย่างสำหรับการเรียน
